百展商城 · AI 客服
一个可运行的电商网站 + 反幻觉 RAG 客服助手。核心不是"能聊天"，而是只依据工具返回的数据回答：商品、平台规则、个人订单都必须查得到才说，查不到就明说不知道；长期偏好记忆有确定性准入规则，并配有可复现的评测集。
核心能力
- 商城闭环：注册登录（JWT）、商品检索与详情、购物车、下单支付、地址管理、未付款订单超时自动关单（Redis 锁 + APScheduler，支持多副本）。
- 混合检索：jieba 中文分词 + PostgreSQL 全文检索 + pgvector 向量召回 + 精确型号匹配，四路候选经 RRF 融合排序；型号来自结构化商品字段，不从标题猜测。
- 客服 Agent：LangChain + DeepSeek，工具闭包绑定 user_id 做数据隔离；系统提示词规定商品/FAQ/订单必须走对应工具，禁止编造价格型号、禁止承诺赔付、拒答与商城无关的请求。
- 回答与记忆护栏：claim_guard 改写无证据的政策断言；memory_policy 校验品牌偏好/常用用途/回答风格，挡住提示词注入；会话摘要与按字符预算的历史窗口防止旧快照和"历史指令"污染回答。
- 可评测：backend/eval/ 收录 golden set、上下文标定、记忆护栏实跑样本与多轮回归结果，测试覆盖鉴权、订单、会话、检索与记忆边界。
