# 评测与历史记录

本目录包含评测脚本、用例集，以及历史运行的原始输出，不是应用运行时源码。
当前客服提示词位于 `../app/rag/agent.py`，页面文案位于 `../../frontend/`。

- `run_*.py`、校准与分析脚本及用例集用于开发和回归评测。
- `results.json`、`calib_*.json`、`p25_runs/`、`p3a_runs/` 和
  `memory_guard_runs/` 等记录对应运行时的输出。
- `memory_guard_runs/*/source_snapshot/` 保存当次评测使用的源码，
  配套运行记录中的 `source_sha256` 用于核对源码完整性。

历史输出和源码快照中出现的旧品牌文案代表当时的真实输入或模型回答。
名称清理不改写这些记录，否则会改变评测证据，并使已有源码哈希失效。
评测结论应结合对应源码版本理解；当前版本的表现需重新运行评测确认。

后端 `.dockerignore` 排除了整个 `eval/` 目录，历史内容不会进入后端镜像构建上下文。
